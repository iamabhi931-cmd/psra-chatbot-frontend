How does the PSRA data pipeline work?
The current pipeline combines the frozen historical Base24 dataset with fresh Karthi Jira data for non-Base24 programs. The combined LIVE table feeds downstream milestone processing and reporting.
What is a GIID?
A GIID identifies the program grouping used by PSRA reporting. The psra_giid_info mapping associates Jira Vehicle Program names with their corresponding GIIDs.
How is the final SRS score calculated?
The final SRS combines HPR, ITS, WART, MIS, and MRR using the documented component weights:

SRS = (HPR × 40%) + (WART × 25%) + (MIS × 15%) + (ITS × 10%) + (MRR × 10%)

Component weights: HPR 40%, ITS 10%, WART 25%, MIS 15%, and MRR 10%.
